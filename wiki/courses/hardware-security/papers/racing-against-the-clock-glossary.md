# Racing against the clock｜名詞解釋

以下用白話解釋論文中的用法；是閱讀輔助，不是所有硬體平台的完整規格。先掌握「時脈域 → 跨域取樣 → 功耗代理訊號」，再讀統計與密碼名詞。

## 時脈與電路

| 名詞 | 白話解釋與本文用途 |
| --- | --- |
| 時脈（Clock） | 電路用來安排狀態更新的節拍；微小頻率／相位變化可能影響不同域的相對時序。 |
| 時脈域（Clock domain） | 由同一時脈驅動的一群電路。CPU 與周邊不一定使用同一節拍。 |
| 非同步時脈域（Asynchronous clock domains） | 不能假定取樣邊緣固定對齊的不同時脈域；不是指「軟體 async 函式」。 |
| 跨時脈域（Clock-domain crossing, CDC） | 訊號從一個時脈域傳到另一域。接收端在自己的邊緣取樣，可能有週期等待差。 |
| 頻率／週期／相位（Frequency / period / phase） | 頻率是每秒幾次，週期是每次多久，相位是邊緣在時間上的相對位置；頻率接近也不等於邊緣對齊。 |
| 鎖相迴路（Phase-locked loop, PLL） | 用相位比較與回授調整輸出時脈的電路；「有鎖相」不表示完全不受供電擾動。 |
| 壓控振盪器（Voltage-controlled oscillator, VCO） | 以控制電壓調整振盪的元件；本文強調它也可能受供電擾動影響。控制端電壓與供電端電壓應區別。 |
| 供電推移（Supply voltage pushing） | 供電變化引起振盪頻率變化的效應；不是程式主動要求 DVFS 的同義詞。 |
| 時序抖動（Jitter） | 邊緣相對預期時刻的偏差；隨機加入抖動不保證消除累積量測中的資料關聯。 |
| 亞穩態（Metastability） | 接收端在敏感取樣時刻附近遇到變化，正反器可能不能立即穩定。本文模擬採理想正反器，實體 FPGA 討論才納入敏感視窗。 |
| ppm | 百萬分之一的相對比例；例如時脈變化 70 ppm 是相對量，不能直接當 70 個週期或 70 奈秒。 |

[HS-010，PDF p.2、7–12、18–19；部分白話定義為依圖文的概念解說](../../../sources/hs-010.md)

## 平台、記憶體與量測資源

| 名詞 | 白話解釋與本文用途 |
| --- | --- |
| 晶片系統（System-on-chip, SoC） | 把 CPU、記憶體控制器與周邊等整合在晶片上的系統；整合在同晶片仍可能有多個時脈域。 |
| 現場可程式化閘陣列（FPGA） | 可配置邏輯與互連的硬體；本文用於建立比商用 SoC 更可控的實驗。 |
| VHDL | 硬體描述語言；本文用它建立時脈與通訊模型，不是以軟體模擬完整商用晶片。 |
| AXI | 本文使用的匯流排／互連通訊介面；圖中跨域元件連接不同時脈下的主從端。 |
| 直接記憶體存取（Direct memory access, DMA） | 硬體引擎搬移資料，無須 CPU 逐筆執行搬移指令；本文用來取得計時序列，仍需要適當的資源存取能力。 |
| 緊耦合記憶體（Tightly coupled memory, TCM） | 緊密連接處理器的記憶體；本文用其與 CPU 同步的特性作為配置比較。 |
| OCRAM | 本文指片上 RAM 區域，在該實驗配置中與處理器非同步；不能把「片上」直接當成「同時脈」。 |
| 資料快取（Data cache） | 保存常用資料的快速層，會影響實際記憶體存取；作者停用它來縮小替代解釋與控制跨域存取情況。 |
| BTAC | Branch Target Address Cache，分支目標位址快取。與資料快取不同；本文發現其狀態會影響早期觀察結果，機制未完全解釋。 |
| DVFS | Dynamic Voltage and Frequency Scaling，動態電壓與頻率調整。主動調節供電／頻率以管理效能功耗；本文關注停用它後仍存在的效應。 |
| RDTSC | x86 讀取時間戳記計數器的指令；本文拿其讀值與系統時間比較，不能一律當作退休指令數。 |
| CLOCK_MONOTONIC | 單調時間介面，不因一般牆鐘校時而直接倒退；本文以經系統校準的時間作比較基準。不是所有裝置都保證獨立物理時脈。 |
| RAPL | Running Average Power Limit 介面；本文在 x86 初探用其功耗／能量讀值作對照，不是所有後續實驗都靠它量測。 |
| RTOS／ThreadX | 即時作業系統／本文使用的 RTOS。執行緒邊界本身不等於已具備任意強度的記憶體與周邊隔離。 |

[HS-010，PDF p.5–10、13–17](../../../sources/hs-010.md)

## 側通道與密碼學

| 名詞 | 白話解釋與本文用途 |
| --- | --- |
| 側通道（Side channel） | 從計時、功耗等實作外在行為推知原本不應外洩的資訊。本文把功耗訊息連到軟體計時觀察。 |
| 恆定時間實作（Constant-time implementation） | 避免依秘密改變典型分支、記憶體存取等時間行為；不等於固定功耗，也不代表所有物理時脈完全固定。 |
| 隱蔽通道（Covert channel） | 發送與接收兩端合作，以非預期通道傳訊；一般側通道中的受害者未必配合。 |
| 代理量測（Proxy measurement） | 用相關的可觀察量間接反映想知道的量。本文的 ticks 差可反映活動，不可直接標成瓦特。 |
| 軌跡（Trace） | 隨時間取得的一串量測值；本文也有整段活動只產生一個總計時值的實驗，兩者不可混稱為相同資料。 |
| 漢明重量（Hamming weight, HW） | 位元字串中 1 的數量；例如 0011 的 HW 是 2。可用作資料相關功耗的簡化模型，但不是所有硬體都完全符合。 |
| 漢明距離（Hamming distance, HD） | 兩個字串不同位元的位置數；常用來描述狀態切換。與單一字串的 HW 不同。 |
| SPA／DPA／CPA | 簡單／差分／相關功耗分析：分別著重可見結構、分組平均差、模型與量測的統計相關。CPA 得到單一 byte 的相關，不能自動等同完整金鑰恢復。 |
| 替代盒（S-box）／SubBytes | S-box 是替代查表或非線性映射；SubBytes 是 AES 的位元組替代步驟。本文早期玩具 S-box 與正式 AES S-box 要分開。 |
| RSA 模冪（Modular exponentiation） | 形如 y＝xᵈ mod n 的運算，RSA 私鑰操作涉及此類計算。本文的簡單示範實作不代表所有具盲化等保護的 RSA。 |
| 遮罩／盲化（Masking / blinding） | 以隨機化內部表示或運算輸入等方式降低秘密與觀察量的直接關係；本文作為防禦討論，未對所有方案逐一驗證。 |

[HS-010，PDF p.1–3、7、13–19、23](../../../sources/hs-010.md)

## 統計與訊號處理

| 名詞 | 白話解釋與本文用途 |
| --- | --- |
| t 檢定／t 值（t-test / t-value） | 比較兩組平均差相對於不確定性的大小。正負號受分組順序影響；|t| 大不等於成功恢復秘密。 |
| p 值（p-value） | 在虛無假設與檢定前提成立時，出現同樣或更極端統計量的機率；不是「虛無假設為真的機率」。 |
| 相關係數（Correlation） | 量化兩個量的線性共同變化；相關不是完整因果證明，也不是密碼破解成功率。 |
| 決定係數（r²） | 在對應回歸模型中，衡量可解釋變異比例；本文 FPGA 例子顯著但 r² 小，顯示效果弱。 |
| 雜訊底線（Noise floor） | 用來對照信號與背景波動的基準。本文繪圖使用 4／√N 參考，其中 N 是量測數；不是所有平台皆適用的安全定理。 |
| 量化（Quantisation） | 連續變化只被記為離散值，例如整數 ticks；少量連續偏移可反映成偶發多一個週期。 |
| 重取樣／零階保持（Resampling / zero-order hold） | 把不規則時間位置的資料轉成共同時間網格；零階保持是在下一筆到達前延續前一個值。 |
| Bessel／Savitzky–Golay 濾波 | 本文用於降低時間序列雜訊、改善圖的可讀性；濾波後曲線不能冒充未處理的原始讀值。 |
| 暫態（Transient） | 開始、結束或狀態轉換附近尚未穩定的效應；本文 RSA 圖中邊界覆蓋不足使部分位元難以判讀。 |

[HS-010，PDF p.5–6、8–9、12–17；p 值定義為統計閱讀補充](../../../sources/hs-010.md)

## 三組最容易混淆的概念

- **執行週期一樣／物理時間完全固定：**兩者不同，還要問「用哪個時間來源觀察」。
- **統計顯著／實際攻擊容易：**前者不是後者，還要交代雜訊、成本、可見位元與完整成功範圍。
- **原文實驗／自己的實測：**本頁全為閱讀整理，沒有執行、沒有自行恢復金鑰。

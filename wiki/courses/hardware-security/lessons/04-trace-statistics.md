# 功耗軌跡、SNR 與統計

## 先把訊號與雜訊的定義說清楚
教材把量測 L 分成操作相關、資料相關、電子雜訊與常數等成分。「雜訊」是相對於目前想解釋的目標；與其他資料有關的切換，對本次模型而言仍可能是干擾。[HS-004，PDF p.3–9](../../../sources/hs-004.md)

同一時間點在多條 trace 上形成一個隨機變數。單條 trace 沿時間有高低起伏，不能直接拿這個起伏當作跨 trace 的洩漏變異。教材也展示功耗與 HW 可能呈反向關係，因此 HW 越大不一定量測值越高。[HS-004，PDF p.4–8](../../../sources/hs-004.md)

## 條件平均與 SNR 的直覺
固定 sample j，依中間值標籤 X 分類：每類的平均反映可解釋的差異，每類內的變動則是同標籤下仍不能解釋的部分。教材的訊雜比（Signal-to-Noise Ratio，SNR）為：

<div class="formula">SNR_j = Var(E[L_j ∣ X]) / E[Var(L_j ∣ X)]</div>

分子是**類別平均之間的變異**；分母是**類別內變異的平均**。比值無單位。分組能明顯分開而組內又集中，SNR 才會高；不是把整條 trace 的最大值除以最小值。[HS-004，PDF p.9–12](../../../sources/hs-004.md)

| 概念 | 在作業一的對應 |
| --- | --- |
| X | 第一輪某個 S-box 輸出的 HW，0 至 8 |
| L_j | 所有軌跡在 sample j 的量測值 |
| E[L_j ∣ X=h] | HW＝h 這一組的平均量測 |
| Var(L_j ∣ X=h) | 同一 HW 組內的變異 |

此表將教材公式套用到題目標籤，題目見 [HS-009](../../../sources/hs-009.md)，實際 Notebook 估計見[作業一](../assignments/assignment-01-snr.md)。

## 分組權重不能一律當九分之一
若每組樣本數為 n_h，總數 N，經驗權重 `w_h=n_h/N`。在已納入的組別上，總平均 `μ=Σ w_h μ_h`；訊號項 `Σ w_h(μ_h−μ)²`；雜訊項 `Σ w_h σ_h²`。均勻隨機 byte 的 HW 並非九類等機率，中間 HW 類別通常較多。[HS-004，PDF p.10；HS-008，cell 22，ID 7aa13ab9](../../../sources/hs-008.md)

這是母體公式的經驗估計。原 Notebook 略過少於兩筆的組別、使用 `ddof=0` 並重新正規化保留組別的權重；分母為零時輸出 0 是程式的數值處理，不能解讀為理論 SNR 確定為零。有限樣本、缺類別與不平衡都要交代。[HS-008，cell 22](../../../sources/hs-008.md)

## SNR 依你選的分組而定
教材同一個觀測時刻用完整 byte 的 HW 與單一 LSB 分組，得到不同 SNR。只分一個 bit，其他 bit 的影響可能留在組內變異。因此比較 SNR 時，要一起說明 X、樣本與 sample 位置。[HS-004，PDF p.11–12](../../../sources/hs-004.md)

DPA 講義談「理想可利用訊號的 SNR」時把物理訊號分解固定；作業估計的是**相對特定 HW 標籤的條件變異比**。兩種定義脈絡要分開，不能一邊換分組、一邊宣稱結果必然不變。[HS-005，PDF p.23–25；HS-004，PDF p.9–12，本文辨析](../../../sources/hs-005.md)

## 協方差與 Pearson 相關係數
協方差（Covariance）描述共同變動方向；Pearson 相關係數把它除以兩邊標準差：

<div class="formula">ρ(X,Y) = Cov(X,Y) / (σ_X σ_Y)</div>

相關係數無單位，介於 −1 和 1；只有兩邊變異不為零時才有定義。負相關也能反映線性關係；相關接近零只表示線性關係弱，不能證明完全獨立。相鄰 sample 常有相關性，但不代表每一個相鄰點都帶來新的獨立證據。[HS-004，PDF p.13–16；相關與獨立性為公式解讀](../../../sources/hs-004.md)

## 多變量、特徵與統計信心
多變量高斯模型（Multivariate Gaussian Model）用平均向量 m 表示各觀測點中心，用共變異數矩陣 C 表示各點變異與共同變動。這是[模板分析](06-template-attacks.md)的基礎。選擇有關聯的點、避免大量冗餘維度，有助於估計；積分、平方和等壓縮也可能移除重要資訊，應依資料評估。[HS-004，PDF p.16–20](../../../sources/hs-004.md)

信賴區間（Confidence Interval）依抽樣模型描述不確定性。常見平均誤差隨 `1/√N` 縮小，需要相應獨立性與分布條件；樣本數加倍不表示誤差就減半。第一類錯誤是拒絕其實成立的虛無假設。教材 Fisher 轉換以 `atanh(r)` 近似分析相關係數的不確定性，不是「超過某條固定線就一定成功」。[HS-004，PDF p.21–28](../../../sources/hs-004.md)

# DPA、CPA 與洩漏模型

## 核心想法：讓模型與量測互相對照
差分功耗分析（Differential Power Analysis，DPA）利用多次運算的統計差異判斷中間值假設。相關功耗分析（Correlation Power Analysis，CPA）則用預測洩漏與實際量測的 Pearson 相關作比較。課程關心的是實作洩漏與模型是否吻合。[HS-005，PDF p.3–14](../../../sources/hs-005.md)

| 面向 | 傳統差分平均 | CPA |
| --- | --- | --- |
| 模型輸出 | 常用某個 bit 將軌跡分成兩組 | 可用 HW 等多值預測 |
| 比較量 | 兩組平均波形之差 | 預測值與每個 sample 的相關 |
| 判讀重點 | 正確分組的差異是否可辨 | 正確假設的相關是否與其他假設區分 |

兩種方式都可能受錯位、雜訊、資料不足與模型不合影響。不是只看到一個高峰就完成所有驗證。[HS-005，PDF p.4–15、23–38](../../../sources/hs-005.md)

## AES 第一輪模型為何能逐 byte 討論
課內的軟體 AES 例子選第一輪 `S(p_b XOR k_b)`，在此處尚未進行 MixColumns，所以模型依賴一個已知明文 byte 與一個候選 key byte。把其結果映射到 HW，是「中間值模型」加上「功耗模型」兩個不同步驟。[HS-005，PDF p.4、9–14](../../../sources/hs-005.md)

把 S-box 值本身、S-box 輸出的 HW，以及某一個輸出 bit 當作三種不同標籤；不能在圖說中互換。作業二使用的脈絡見[作業二頁](../assignments/assignment-02-cpa.md)。

## 相關曲線的每個方向代表什麼
在固定 byte 與固定假設下，相關曲線沿 sample index 展開，反映該假設在哪些時刻與量測吻合。把每個候選跨 sample 的最大絕對相關整理成分數，則是另一層彙整。正、負相關的符號與量測方向有關，選擇絕對值時必須在軸標與文字中明示。[HS-005，PDF p.12–16、23–25，本文圖表解讀](../../../sources/hs-005.md)

| 圖形 | 改變的量 | 能回答的問題 |
| --- | --- | --- |
| correlation vs. sample point | 時間／sample index | 哪個時間區域與某個假設相關？ |
| maximum correlation vs. number of traces | 使用軌跡數 N | 增加資料後，假設是否逐漸可區分？ |

這兩類圖是作業二的明確要求，不是從講義自行推定的交件格式。[HS-009，作業二原題](../../../sources/hs-009.md)

## 模型吻合與 SNR 是不同因素
教材在加性雜訊且訊號與雜訊滿足所列獨立性假設時，寫出：

<div class="formula">ρ(H,L) = ρ(H,P_exp) / √(1 + 1/SNR)</div>

H 是模型預測，P_exp 是所關心的實際訊號，L 是含雜訊量測。雜訊降低時，相關上限仍受模型吻合程度限制；錯誤模型不是只靠更多樣本就一定能補救。反過來，模型合適也可能被量測雜訊淹沒。[HS-005，PDF p.23–29](../../../sources/hs-005.md)

教材的「約 20 條」「160 條」等是特定實驗比較，不是通用需求。題目說 200 條應足夠，是作業的預期條件，不能預先寫成使用者已成功的實驗結論。[HS-005，PDF p.15、33–36；HS-009](../../../sources/hs-009.md)

## 換平台時，不能照搬模型
MCU 的序列運算、平行硬體 AES、暫存器重用與最後一輪中間值，具有不同的資料關係。HD 模型要知道舊值與新值；平行運算的其他 S-box 可能變成目前 byte 模型的干擾。零值模型則針對教材特定實作，不是所有 S-box 都自帶相同零值特徵。[HS-005，PDF p.16–22、26–31](../../../sources/hs-005.md)

## 常見判讀錯誤
| 容易誤解 | 正確理解 |
| --- | --- |
| 最大峰就是正確金鑰 | 需比較其他候選、不同 byte 與額外驗證 |
| N 增加，正確分數一定單調上升 | 有限樣本的估計會波動；看可分離性與穩定性 |
| 相關接近 0 等於沒有任何洩漏 | 只針對目前線性模型、時間區域與資料量 |
| SNR 峰值 sample 必是 CPA 唯一最佳位置 | 分組、模型與樣本不同，兩者不保證逐點等價 |
| 一個 byte 成功等於 128-bit key 全部成功 | 十六個 byte 都需要對應證據 |

前兩項對應 HS-005 PDF p.23–36 的模型與估計限制；後三項為與 HS-004 PDF p.9–16、HS-009 原題的綜合理解。

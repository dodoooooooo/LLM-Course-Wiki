# 硬體安全導論與威脅模型

## 先抓住這門課的問題
密碼演算法在數學上難以破解，不代表執行它的裝置不會洩漏資訊。硬體安全（Hardware Security）把觀察範圍從程式輸入與輸出，擴大到實體裝置的功耗、時間、電磁訊號與異常行為。重點是「實作是否保住了演算法的假設」。[HS-001，PDF p.2–8、25–36](../../../sources/hs-001.md)

資訊安全的 CIA 三要素：機密性（Confidentiality）保護資訊不被未授權得知；完整性（Integrity）避免未授權修改；可用性（Availability）確保服務能使用。資產可能是金鑰、韌體、設計 IP，也可能是服務能力。[HS-001，PDF p.2–8](../../../sources/hs-001.md)

## 威脅模型：先說清楚誰能做什麼
威脅模型（Threat Model）要回答保護什麼、對手想得到什麼、能接觸什麼、具有多少設備與時間。對手只看遠端回應，與能長時間持有實體裝置，是兩種不同假設。安全成本必須與資產價值、實作成本與攻擊者資源一起考量。[HS-001，PDF p.9–11](../../../sources/hs-001.md)

**自編理解例子**：校園借用卡的資產是認證金鑰；「知道演算法」不等於「知道金鑰」；「持有一張卡」也不等於「可讀出晶片內全部狀態」。說明防禦效果前，應先界定允許對手觀察與控制的介面。

## 分類有兩條軸，不能混在一起
| 分類軸 | 類別 | 判讀重點 |
| --- | --- | --- |
| 是否改變正常執行 | 被動 Passive | 觀察運算留下的訊號 |
| 是否改變正常執行 | 主動 Active | 刻意擾動執行或輸入條件 |
| 接觸程度 | 侵入式 Invasive | 暴露並直接接觸晶片內部結構 |
| 接觸程度 | 半侵入式 Semi-invasive | 暴露晶片但不直接接觸內部導線 |
| 接觸程度 | 非侵入式 Non-invasive | 不需暴露晶片內部，可從外部量測或互動 |

被動／主動和侵入程度是不同維度。功耗分析通常是被動側通道；故障注入（Fault Injection）屬於主動擾動。不要把「非侵入」誤認成「被動」或「沒有風險」。[HS-001，PDF p.16–24](../../../sources/hs-001.md)

## 側通道、SPA 與統計分析
側通道（Side Channel）利用正常功能之外、與內部運算相關的可觀察資訊。相同明文與金鑰決定中間值，中間值與電路切換有關，切換再影響功耗。這條關係不代表每個時間點都能清楚看見秘密。[HS-001，PDF p.26–36](../../../sources/hs-001.md)

| 方法 | 核心想法 | 需要注意 |
| --- | --- | --- |
| 簡單功耗分析 SPA | 從少量波形辨認操作或流程差異 | 很依賴實作知識與可辨識的訊號 |
| 差分功耗分析 DPA | 對多條軌跡依中間值假設分組後比較 | 需有合適的統計量與資料關聯 |
| 模板分析 Profiling | 用參考裝置學習條件機率分布 | 參考與目標裝置的分布可能不同 |

DPA 與 CPA 的細節在[第五主題](05-dpa-cpa.md)，模板的額外假設在[第六主題](06-template-attacks.md)。這裡的區別是觀察方式與先驗知識，不是保證需要幾條軌跡。[HS-001，PDF p.35–36](../../../sources/hs-001.md)

## 防禦方法要對照洩漏來源
| 方法 | 主要方向 | 限制與代價 |
| --- | --- | --- |
| 隱藏 Hiding | 降低資料與觀測訊號的關聯，例如增加雜訊或打散時間 | 額外成本；可能仍被平均或重新對齊 |
| 遮罩 Masking | 用隨機分享值改變中間表示 | 正確性與獨立性假設重要；非所有階數都自動安全 |
| 分區 Partitioning | 隔離敏感區域的電源、時脈或測試介面 | 需看實際隔離邊界與交互作用 |
| 抗竄改 Anti-tamper | 偵測或提高實體存取成本 | 效果依威脅模型與環境而定 |

降低功耗洩漏不表示電磁洩漏也完全消失；加入雜訊也不等於已證明沒有洩漏。評估要指出量測管道、模型與條件。[HS-001，PDF p.28–43](../../../sources/hs-001.md)

## 名詞與回想
| 名詞 | 要能說出的重點 |
| --- | --- |
| Threat Model | 資產、對手能力、接觸範圍與資源 |
| Side-channel Leakage | 實作所產生、與內部資訊相關的外部訊號 |
| Hiding／Masking | 改變可觀測訊號／改變中間值表示 |
| MCU／FPGA／ASIC | 軟體執行平台／可重組邏輯／專用積體電路 |

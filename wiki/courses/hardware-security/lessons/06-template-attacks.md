# 模板攻擊與機率判讀

## 先分清模板分析多知道了什麼
模板攻擊（Template Attack）屬於剖析式方法（Profiling）：先在可控制的參考裝置建立不同中間值的量測分布，再用目標觀測比較哪一種分布較合理。參考裝置的可取得性、可控制性，以及能否代表目標裝置，是額外假設。[HS-006，PDF p.3–10](../../../sources/hs-006.md)

| 階段 | 輸入 | 產物 |
| --- | --- | --- |
| 剖析 Profiling | 已知類別的多次參考量測 | 各類別平均向量與共變異數矩陣 |
| 比較／推論 | 目標量測的特徵向量 | 在各類別模型下的似然與排序 |

模板不是一張固定波形圖片，也不是把兩條線目測疊起來。它同時描述訊號中心與隨機變動。[HS-006，PDF p.7–10](../../../sources/hs-006.md)

## 平均向量與共變異數矩陣
選 d 個關注點（Points of Interest，POIs），每次觀測變成 d 維向量 t。某個類別 h 的模板為 `(m_h,C_h)`：m_h 長度 d，C_h 為 d×d 矩陣；對角線是各點變異，非對角線是兩點的共變異數。[HS-006，PDF p.8–9；HS-004，PDF p.16](../../../sources/hs-006.md)

**自編理解例子**：兩個觀測點總是一起升降，不能把它們當兩份完全獨立的證據；C 描述這種共同變動。只比每個點離平均多遠，會漏掉方向與尺度。

## 最大似然：越大越合理
多變量高斯的對數似然可寫為：

<div class="formula">log p(t ∣ h) = −½[(t−m_h)ᵀ C_h⁻¹(t−m_h) + log det C_h + d log(2π)]</div>

在候選 h 之間選**最大的 log p**，等價於選最大的 p，因為 log 是單調遞增函數。取 log 是為了把乘法變加法並改善數值穩定性，不是改變優劣方向。[HS-004，PDF p.16；HS-006，PDF p.10–11、15](../../../sources/hs-006.md)

講義 p.11 的簡記含 `|ln p|`，不應泛化成「最小絕對對數值」。機率密度可大於 1，log 密度也可為正；普遍正確的判準仍是最大似然／最大對數似然。p.15 範例的 −5.98 比 −49.54 大，因此前者較合理。[HS-006，PDF p.10–11、15，本文數學辨析](../../../sources/hs-006.md)

## 為什麼不能隨意省掉 C
教材的 reduced template 只保留平均向量並比較歐氏距離。這可視為各類別具有共同且等向性共變異數等條件下的簡化；若類別的散布大小、方向不同，只比平均距離可能與完整似然給出不同結果。[HS-006，PDF p.12；由高斯公式推得的條件說明](../../../sources/hs-006.md)

估計 C 需要足夠樣本；POI 太多、樣本太少或特徵高度重複，可能使矩陣難以反轉。更多維度不一定更準，應與[統計主題](04-trace-statistics.md)的點間相關一起理解。[HS-004，PDF p.13–20；本文估計限制](../../../sources/hs-004.md)

## 教材 MOV 與 key schedule 圖怎麼看
MOV 範例依搬移 byte 的 HW 形成九種分布，再選五個 POI。這裡的「九」來自 8-bit HW 的 0 至 8，而非只有九種 byte 值。「五」是該例選取的維度，不是模板分析的固定參數。[HS-006，PDF p.13–15](../../../sources/hs-006.md)

金鑰擴展（Key Schedule）本身也處理與金鑰相關的中間值。教材以多個 HW 條件縮小候選集合，圖中的剩餘候選數只屬於該例的觀測與假設，不能當通用保證。[HS-006，PDF p.16–17](../../../sources/hs-006.md)

## 合併多條觀測與 Bayes 關係
條件獨立的量測可將似然相乘，或把 log 似然相加；後驗機率還要結合先驗並正規化。必須先交代獨立性與類別定義，不能把強相關的重複特徵當作無限增加的獨立證據。[HS-006，PDF p.18–19](../../../sources/hs-006.md)

更多有效資料通常有助於辨別，但有限樣本下，正確候選的後驗不必每加入一條 trace 就單調增加。模型偏移或不合適的模板也可能累積錯誤證據。這是機率判讀限制，不是使用者已觀察到的實測現象。[HS-006，PDF p.18–19，本文解讀](../../../sources/hs-006.md)

## 與 CPA 的比較
| 比較 | CPA | Template |
| --- | --- | --- |
| 主要模型 | 預測洩漏與量測的線性相關 | 類別條件下的量測分布 |
| 剖析階段 | 課內基本例不需另建參考模板 | 需參考量測建立模板 |
| 描述變動 | 通常用單點相關 | 可包含多點共變異數 |
| 失效來源 | 模型不合、雜訊、錯位 | 另有剖析不足、裝置差異、分布假設不合 |

比較依 HS-005 PDF p.9–14、HS-006 PDF p.7–12 重整。現在兩份作業要求 SNR 與 CPA，未將模板分析另當第三份作業。

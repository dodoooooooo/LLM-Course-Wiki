## 與作業一相同與不同之處
作業一使用已知實驗金鑰形成 HW 標籤，量化資料相依的變異；CPA 則比較候選中間值與量測的相關性。使用相同資料不代表兩個統計量相同。原本的 SNR 圖能幫助理解時間區域，但不能當作 CPA 的兩類圖。[HS-004，PDF p.9–12；HS-005，PDF p.9–15](../../../sources/hs-005.md)

第一輪模型涉及 `S(p_b XOR k_b)`；S-box、HW、key byte 與 sample index 分別代表非線性轉換、洩漏近似、待比較假設及量測時間位置。這四者要在報告中清楚區分。[HS-005，PDF p.4、13–14](../../../sources/hs-005.md)

## 圖一：correlation vs. sample point
| 元素 | 應交代的內容 |
| --- | --- |
| 橫軸 | sample point；有量測率才可另換算時間 |
| 縱軸 | Pearson correlation，或明示 absolute correlation |
| 每格 | byte 編號與固定使用的 N |
| 線條 | 哪個候選／哪些比較曲線，圖例定義一致 |
| 圖說 | 峰值位置、候選間是否可區分、是否有負相關 |

這是依題目與 HS-005 PDF p.12–16 的自編檢查方式，未宣稱教師要求特定配色或一定要畫所有候選。若只顯示選出的候選，需在文字交代選擇方式，避免把選擇過程藏起來。

相關係數的符號與量測方向可能有關；負峰不應直接被忽略。使用最大絕對相關作彙整時，縱軸應寫 `|correlation|`，不能把絕對值線說成保留正負號的原始相關。[HS-005，PDF p.23–25，公式解讀](../../../sources/hs-005.md)

## 圖二：maximum correlation vs. number of traces
| 元素 | 應交代的內容 |
| --- | --- |
| 橫軸 | 使用的 trace 數 N |
| 縱軸 | 跨 sample 的最大相關或最大絕對相關，明示定義 |
| 每格 | 同一個 key byte |
| 比較基準 | 正確值／選出的值／其他候選的區別 |
| 固定條件 | sample 範圍、資料順序與前處理 |

這一類圖討論「資料增加時，候選是否能穩定區分」，與圖一討論「何時發生相關」不同。資料前綴與隨機子集也不是同一實驗，圖說需明示選法。以上為原題的自編分析說明。[HS-009；HS-005，PDF p.32–36](../../../sources/hs-009.md)

正確候選的估計相關不必單調上升。若不同 N 時反覆更換 sample 視窗或資料處理，分數變化會混入其他因素。有限樣本下的最高分也不能自動等同完整 key 已正確恢復。[HS-005，PDF p.23–36，本文解讀](../../../sources/hs-005.md)

## AI 建議：結果紀錄框架
**以下是自編整理框架，尚未填入實測結果**：

| 欄位 | 記錄方式 |
| --- | --- |
| 實驗資料 | 原檔、選取的 N、samples 範圍、t 與 p 的對應檢查 |
| 模型 | 第一輪何種中間值、HW／其他模型與原因 |
| 每個 byte | 選出的候選、比較依據、兩類圖的對應位置 |
| 已知 key 驗證 | 實驗 key 僅作結果比對，不把它預填為恢復輸出 |
| 全部 16 bytes | 全部是否一致；失敗 byte 個別列出，不只報成功者 |
| 限制 | 雜訊、錯位、資料量、模型、數值例外等 |

這些欄位為可追溯紀錄建議，不是教師新增規定。若相關分母為零或出現 NaN，應列為未定義／需處理，不能默默當成可靠高分或低分。[HS-004，PDF p.14；本文數值說明](../../../sources/hs-004.md)

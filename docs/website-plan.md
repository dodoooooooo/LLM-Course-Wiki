# 複習網頁目前狀態

狀態：保留離線本機版，並已設定 GitHub Actions 從 main 建置／檢查，再發布 dist/ 到 GitHub Pages；網站與公開儲存庫入口見 README；儲存庫已公開，Pages 工作流程尚受平台限制而未上線。

- 課程首頁依 `wiki/courses/*/index.md` 自動列出課程，不限制課程數；高等軟體工程內分課程與測驗，兩者各四章。
- 課程來自 Markdown，含表格、程式碼、來源頁碼及 SVG 圖例。
- 全文搜尋已匯入的課程與作業內容；分章練習／交卷模式；題型篩選、隨機題序、錯題複習。
- 單選／填空自動評分；英文忽略大小寫與空白。手寫附要點另行自評，繪圖區可筆畫、復原、清空與保留草稿。
- localStorage 保存作答及草稿，JSON 匯出／匯入。沒有後端、跨裝置同步或線上 LLM 問答。
- 根目錄 index.html 可雙擊開啟；scripts/build.py 從唯一內容來源重建。

後續：持續增加課程、教材、作業與論文；按真實使用回饋改善內容與題庫。若要同步或部署，另確認權限與需求。

## 硬體安全已實作更新
硬體安全只有課程／作業兩個主入口。七份講義對應七個主題；兩個作業頁分開需求、觀念、已保存成果與待補證據。全文搜尋涵蓋目前已匯入的課程與作業，新增課程會自動納入；每篇有目錄與課程互連。硬體安全閱讀標記獨立於軟工四章，不推定作業完成。來源摘要可在網頁中閱讀。尚未加入 paper 報告或硬體安全測驗。

## 後續課程
首頁、側欄與課程數由 Wiki 課程索引產生。新增課程 Markdown 具有通用閱讀路由與全文搜尋，既有 `/ase`、`/hs` 路由保留，避免破壞書籤與學習紀錄。新課程以分類 `kind: quiz` 及既有 Markdown JSON 題庫格式使用共用測驗功能。

## 課程與分類資料模型
所有課程均採相同的建置及呈現流程，沒有特定課程的前端分支。課程由 Wiki 目錄發現，分類由每門課的 `course.json` 指定；未提供設定時，依子目錄的 `index.md` 發現分類。分類可用任意顯示名稱與資料夾名稱。頁面數、題數、閱讀分母與來源摘要列表均於建置或呈現時從實際資料計算。

舊 `/ase`、`/hs` 與其內容網址，以及舊閱讀／測驗紀錄識別碼，放在對應課程設定中保留；新增內容使用自動路由。所有 Wiki Markdown 頁面都有閱讀路由與搜尋資料，包含跨章概念與來源摘要。

## 視覺系統：新粗獷主義 × Zine 拼貼

共用樣式在 `web/styles.css`，建置時內嵌，無外部字體／素材依賴。首頁為黑白亮黃海報、大字、編號及幾何拼貼；課程內頁用穩定 ID 雜湊選定單一亮色，基底、框線、字體及陰影規則一致。點綴色不依課名或排序，也不修改學習紀錄。

正文維持白底、充足行距與閱讀寬度；卡片採粗黑框、硬邊偏移陰影，正文不傾斜。表格、公式、程式碼與圖表保留獨立可讀區域。分類頁籤可換行、卡片在窄寬度改單欄；避免裝飾跨出頁面形成橫向溢出。詳細數值與後續維護規則見 AGENTS.md 第 15 節。
